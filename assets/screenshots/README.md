# Project Screenshots

Store the important screenshots of the Streamlit demo in this folder.

## Recommended screenshots

- Overview / traffic upload screen
- Rolling infiltration-probability timeline
- K-step forward simulation table (MITRE ATT&CK stage per step)
- Attention-weight and feature-saliency charts (explainability)
- Flagged flows / drill-down table
- `reports/benchmark.md` results (world model vs baseline)

## Naming convention

Use clear names such as:

- `01-overview.png`
- `02-timeline.png`
- `03-rollout.png`
- `04-explainability.png`
- `05-flagged-flows.png`
- `06-benchmark.png`

Do not upload screenshots containing passwords, API keys, tokens, personal credentials, or other sensitive information.

## Adding screenshots to README

You can display important screenshots in the main `README.md` using a relative path, for example:

```md
![Infiltration timeline](assets/screenshots/02-timeline.png)
```
